# 汉字识字

给小学生用的汉字学习应用。输入一段文字，看清每个字的拼音、笔顺动画和朗读。

原生 Android（Kotlin + Jetpack Compose），面向 Android 12 及以上的平板和手机。全部数据随应用打包，**不需要联网，也不申请任何权限**。

---

## 功能

**输入文字** — 输入一整段中文，按「确认」，应用会为每个字查出拼音、加载笔顺，并显示成一个字卡网格。也可以用「粘贴」把剪贴板里的文字放进输入框。输入里的换行会让字卡另起一行（连着敲几个换行只换一行）。

**历史记录** — 按过「确认」的文字会自动存在输入框下面，每条带确认时间（精确到秒），最新的在最上面，最多 30 条，超过就丢掉最旧的一条；同一句再确认一次是把它移到最前、时间刷新，不会存两份。每条左边是「删除」，右边是「编辑」（放回输入框改）和「学习」（直接进字卡网格）。手机竖屏时历史记录在下方、只有它滚动；平板或手机横屏时输入框在左、历史记录在右。

**拼音** — 拼音由上下文推断，同一个字在不同词里读音不同时会自动选择正确的那个。比如「长江」读 cháng jiāng 而不是 cháng zhǎng。多音字下方会标出，可以点开切换成其他读音。

**笔顺动画** — 点任意字卡打开详情，笔顺按真实顺序逐笔演示，带虚线格子辅助线（田字格）。

**朗读** — 点字卡上的喇叭念当前这个字，播放的是随包分发的音节录音。

**设置** — 四个开关，都会被记住（新装的应用四个都是打开的）：

| 开关 | 作用 |
|---|---|
| 展示拼音 | 字卡上是否标注拼音 |
| 笔顺动画 | 关掉则直接显示完整字形，不演示 |
| 语音朗读 | 字卡上是否显示喇叭按钮 |
| 屏幕常亮 | 学习时不自动锁屏 |

手机上放不下标题、四个开关和「编辑」，所以输入页默认把四个开关铺在第二行、按「收起设置」收起来；进了字卡页面自动收起，点「显示设置」可以再展开。平板宽度够，一直平铺显示。

## 安装

从源码构建需要一个 Android 开发环境（JDK 17、Android SDK 37、Gradle 由 wrapper 自动下载）。

```bash
git clone <本仓库>
cd hanzi-literacy-android

./gradlew :app:assembleDebug        # 构建
./gradlew :app:testDebugUnitTest    # 跑测试
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`，用 Android Studio 打开项目直接点运行也可以。

> **首次构建会慢一些**，约 10 分钟。应用里有 50MB 笔顺数据、14MB 音节录音和 12MB 分词模型，构建脚本还会跑一次资源合并（`tools/merge_assets.py`）。之后增量构建只要几秒。

**安装到设备**：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 已知限制

- **包体积大。** Debug 包约 119MB，Release 包约 55MB。数据本身（笔顺 50MB + 音节库 14MB + 分词模型 12MB）是无法再压缩的。
- **只覆盖常用字。** 笔顺和释义数据来自 cnchar，约 1.8 万个汉字。生僻字可能查不到，此时字卡仍会显示，但没有笔顺动画。
- **朗读是预录音节。** 单字读音来自随包的音节库，语速和音色是固定的，无法调整；没有整句朗读。
- **无导入导出。** 历史记录只存在应用里，不能导出或导入文件；没按过「确认」的草稿关掉应用就没了。
